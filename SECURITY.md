# Security Policy

AegisGuard is a local educational prototype. It is not production-ready and
has not completed an independent security assessment.

Do not expose the current service to public traffic. It has no production
certificate provisioning, key rotation, administrator authentication or
operational monitoring.

Do not report vulnerabilities in public issues. Use GitHub's private
vulnerability reporting for this repository when available. If it is
unavailable, contact the maintainer through the GitHub profile.

Reports should include the affected commit, configuration, reproduction steps
against a local copy and the impact. Do not include real credentials,
certificates or player data.
