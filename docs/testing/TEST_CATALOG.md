# Test catalogue

Commands assume the repository root and an existing CMake build directory.
The full CTest suite currently takes about twelve seconds on the development
machine; exact runtimes vary by host.

| Suite | Purpose and location | Command and dependencies | Current result or evidence |
|---|---|---|---|
| Unit | Validate simulation, session store, protocol, rule detection, queues, rate limits, replay, movement statistics and Quadtree behavior in `tests/unit/`. | `ctest --test-dir build-audit-fresh --output-on-failure`; CMake, C++20, GoogleTest. | 98/98 CTest tests passed on 2026-10-25. |
| Integration | Exercise TLS, credentials, deadlines, replay, per-connection/per-IP limits, detection findings, oversized frames and simulation dispatch. | Included in the CTest command; OpenSSL, Asio and loopback sockets. | Loopback tests cover IP rate state across reconnect, explicit HELLO and rejected oversized input. |
| Python utility and log parsing | Verify benchmark JSON sanitization, benchmark graph generation, server JSONL output, 100-line parsing and secret exclusion in `tests/python/`. | `python -m unittest discover -s tests/python -p "test_*.py" -v`; Python standard library and a built CMake tree. | 8/8 tests passed on 2026-10-25; 160 raw benchmark repetitions across eight cases rendered; 100 logger lines and 14 server-run lines parsed. |
| End-to-end | Verify loopback TLS authentication, HTTPS health/status authorization, movement submission and signal shutdown. | `test_server_smoke.py`; requires the built server and OpenSSL. | Valid token accepted; health returned 200; unauthenticated status returned 401; valid client certificate returned 200; shutdown exited 0. |
| Protocol conformance | Check version 2 HELLO, movement frame boundaries and rejection cases in `tests/unit/protocol_test.cpp` and `network_service_test.cpp`. | CTest command; GoogleTest. | Version 1, malformed, replayed and incomplete frames are rejected. |
| Property and differential | Compare spatial queries with an independent map scan. | CTest command; fixed seed in `tests/unit/quadtree_test.cpp`. | 600-operation deterministic sequence; RapidCheck is not added. |
| Coverage-guided fuzz | Challenge the decoder with generated byte sequences in `tests/fuzz/protocol_fuzz.cpp`. | Configure with Clang and `-DAG_BUILD_FUZZERS=ON`; see [protocol fuzzing](PROTOCOL_FUZZING.md). | Harness added. No local run: Clang is unavailable. |
| Stateful/model-based | Replay recorded simulation inputs from their initial state. | `ReplaySessionTest` records and replays bounded input ticks. | Deterministic replay is tested; broader model-based match testing remains deferred. |
| Mutation | Verify tests detect deliberate changes to important validation. | No mutation tool or mutation run is configured. | Deferred. |
| Security/authorization | Verify credentials, replay, per-connection/per-IP rate limits and bounded unauthenticated requests. | CTest command; local loopback service only. | Reconnect-persistent per-IP rate state and oversized-frame rejection have tests. |
| Adversarial anti-cheat | Verify protocol rule signals and evaluate the offline movement heuristic. | Rule detector tests, TLS service integration and `MovementStatisticsEvaluationTest`; synthetic traces only. | Eight protocol violations produce explainable findings. A disjoint seeded holdout test measures 40 true positives and 40 true negatives on constructed movement patterns; it does not estimate gameplay detection quality. |
| ML evaluation | Assess whether a model adds value over the deterministic baseline. | `MovementStatisticsEvaluationTest` evaluates a fixed heuristic on 80 seeded holdout traces. | Measured synthetic holdout metrics are documented. No learned model or real-player corpus exists; inference is not justified. |
| Concurrency | Check supported concurrent access and thread confinement. | CTest command; standard C++ threads. | Session-store validate/revoke stress test added. ThreadSanitizer was not run. |
| Performance and scalability | Measure spatial microbenchmarks and later service capacity. | See [performance plan](PERFORMANCE_TEST_PLAN.md); Google Benchmark for spatial work. | The graph contains 20 raw repetitions and p50/p95/p99 for eight spatial query cases. Network capacity and latency percentiles are unmeasured. |
| Soak and endurance | Detect long-run resource growth and recovery issues. | Not configured. | Deferred. |
| Fault injection and resilience | Exercise dependency, disk, network and process failures. | See [resilience plan](RESILIENCE_TEST_PLAN.md). | Network timeout and rejection cases pass. Other faults are deferred. |
| Backup and restore | Validate persisted data recovery. | No persistent store exists. | Not applicable yet. |
| Container and infrastructure | Check images, runtime configuration and IaC. | The runnable server target exists; container and IaC files are not implemented yet. | Deferred. |
| Supply chain | Check dependencies, static analysis, SBOM and workflow permissions. | CI builds/tests, CodeQL, Scorecard and Syft-based source SBOM are configured in GitHub Actions. | Workflows have not run remotely. Trivy and Dependency-Check are deferred because no supported C++ lockfile or deployment target exists; no findings are claimed. |
| API and dashboard | Validate the HTTPS status surface and authorization. | `tests/python/test_server_smoke.py`; loopback HTTPS. | Health is public; status and metrics require a trusted client certificate. No dashboard exists. |
| Accessibility | Check keyboard, screen-reader and contrast behavior. | Requires a dashboard. | Not applicable yet. |
| Regression | Preserve fixes with focused tests. | Included in CTest. | Current cases include rejection, timeout, replay and concurrency regressions. |
| Release acceptance | Verify the release checklist against actual commands and artifacts. | See [release acceptance](RELEASE_ACCEPTANCE.md). | Release gate is open. |
| Clean install and reproducibility | Configure and build from a clean checkout. | CMake configure/build/CTest and Python unittest commands in the README and CI workflow. | Local non-network C++ and Python checks pass; current GitHub workflow configuration has not run yet. |
